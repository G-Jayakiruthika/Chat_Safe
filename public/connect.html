Use Chat_Safe inside the apps you already use

Forward or paste a suspicious message to the Chat_Safe bot. Kavach replies with the risk score, the warning signs and what to do, in the same language you wrote in.

For the person deploying Chat_Safe

Each connector switches on when its keys are set as environment variables on the server (for example in Google Cloud Run). Secrets never reach the browser.

✈️ Telegram bot

  1. Create a bot with @BotFather and copy the token.
  2. Set TELEGRAM_BOT_TOKEN, a random TELEGRAM_WEBHOOK_SECRET and TELEGRAM_BOT_USERNAME.
  3. Register the webhook:

🟢 WhatsApp Business (Cloud API)

  1. In Meta for Developers, add the WhatsApp product to your app.
  2. Set META_APP_SECRET, META_VERIFY_TOKEN, WHATSAPP_TOKEN, WHATSAPP_PHONE_NUMBER_ID and WHATSAPP_DISPLAY_NUMBER.
  3. Callback URL: , then subscribe to messages.

📸 Instagram DMs

  1. Add Instagram messaging to the same Meta app (professional account).
  2. Set INSTAGRAM_TOKEN, INSTAGRAM_ACCOUNT_ID and INSTAGRAM_USERNAME.
  3. Use the same callback URL and subscribe to messages.

💬 Facebook Messenger

  1. Connect a Facebook Page to the Meta app.
  2. Set MESSENGER_PAGE_TOKEN and MESSENGER_PAGE_USERNAME.
  3. Same callback URL, subscribe the Page to messages.

Security: Telegram requests must carry the secret token; Meta requests must carry a valid X-Hub-Signature-256 HMAC. Anything else is rejected with 401. Duplicate deliveries are ignored.
